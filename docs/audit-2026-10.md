# Audit — October 2026

Whole-repo review (renderer core, studio + API, terminal / MCP / registry). What was wrong, what
changed, and what's left. Findings were verified by reading code or reproducing them.

## Fixed

### Security / cost
- **`/api/generate` was an open LLM proxy.** Now: zod-validated body (400 on bad shape), per-turn and
  total transcript caps, cross-site requests rejected (`Origin` / `Sec-Fetch-Site`), per-IP sliding
  window rate limit on the gateway engine (in-memory per instance — pair it with a Vercel Firewall
  rate-limit rule and an AI Gateway budget for a hard ceiling). Gateway errors and truncated replies
  (`finishReason: length`) now reach the user as a `⚠` line instead of "try rephrasing".
- **Local Claude Code reachable from the LAN.** `next dev` binds `0.0.0.0` and the loopback guard
  trusts the `Host` header, which a LAN client can forge. `pnpm dev` now binds `127.0.0.1`;
  `pnpm dev:lan` opts back in (Claude Code engine then refuses non-loopback `x-forwarded-for`).
- **`claude -p` stream**: EPIPE on stdin no longer crashes the dev server; cancelling the response
  kills the child.
- **Share links**: payload is type-checked; `buildCode` escapes every interpolated value (a crafted
  `fontKey` could inject code into "Copy code").

### Untrusted input that could freeze the tab
- One config sanitizer (`sanitizeConfig` in `lib/ascii/config.ts`) clamps every key to a safe range,
  checks enums / colours, caps charset length and strips control characters. Used by
  `mergeConfig`, pieces, share links and AI replies. (`smooth: 1e7` was 10M blur passes;
  `inertia > 1` spun to NaN; 40k-glyph charsets overflowed an `Int16Array`.)
- `parseWorld` caps objects / fields and scales particle counts down to a total budget.
- `parseScene` caps prims / dabs / paint, clamps `blend`, renormalises and caps imported mesh
  triangles at parse time.
- Text sources are length-capped and the text canvas stays under browser canvas limits.

### Data loss
- Opening a share or gallery link no longer overwrites the saved session's scene (paint, meshes).
  The hash is applied on top of the restored session, then removed from the URL so a reload shows
  the latest work.
- Restores are independent (a corrupt scene no longer aborts the world restore); a full
  `localStorage` shows a one-time warning.
- Undo/redo now restore the source kind and active preset (undoing an AI scene returns to the mark
  you were on).

### Renderer
- `getText()` no longer returns a stale frame after an empty model.
- Reduced motion also stops shimmer, wave and scanline effects.
- Visible keyboard focus ring on the canvas.

### AI chat
- IME composition no longer submits; failed turns aren't resent as history; switching engine resets
  the Claude session; a home-page prompt still sends if `/api/agent` fails; screen readers get one
  status announcement per turn instead of every streamed chunk.

### Terminal, MCP, registry
- **Registry items didn't compile once installed** (missing `world-assets.ts`, agent / handoff files,
  `/api/agent`). Fixed, and `lib/registry.test.ts` now checks every item's import closure and
  package dependencies.
- **MCP path escape**: symlinks could lead reads and writes outside the studio folder, and
  `read_piece` read any file (e.g. `.env.local`). Paths are now resolved through symlinks and confined
  to the root, only `*.ascii.json` (+ frame) files can be read or written, and dotfiles are refused.
  Images in pieces must be relative paths inside the folder (remote images:
  `OHMYASCII_ALLOW_REMOTE_IMAGES=1`). `write_piece` is marked destructive.
- **CLI**: the terminal is restored on crashes and SIGHUP. Flags are validated (unknown flags and bad
  values exit 2). Status and list lines fit the terminal width. `--watch` survives atomic saves.
  Resizes are debounced. Added `-v`. `play -` refuses an interactive stdin. Colour detection honours
  `TERM=dumb` and `FORCE_COLOR`, and `render` to a pipe is plain.

### Studio drawer (UI)
- One **Image · Text · Model · Scene** tab bar replaces the three toggle buttons ("Composing — back to
  marks") and the "use text as source" switch. Each tab shows only its own controls, and switching
  back keeps the mark / upload / text you had. The Scene tab no longer resets your world to its
  gallery preset.
- Look, Characters and Color are one **Look** section: preset, characters, cell size, colour mode and
  swatches. Typeface, aspect, glyph scale, transparency and the grid are under *More type &
  background*. Light, Shape and Motion keep their common controls up front; the rest (tone,
  silhouette, camera and interaction) are in collapsed groups. Effect sub-sliders only appear once
  the effect is on.
- X / Y / Z settings are one row each (`VecField`: type, or drag the axis letter to scrub) instead of
  three sliders. This applies to model shapes, world objects, arrays, drift, spin, base rotation and
  the camera.
- Model panel: dropped the tool picker and brush settings, which duplicated the canvas toolbar. File
  and reset actions are under *Files & reset*.
- Scene panel: the 36-button gallery is a dropdown with ‹ › stepping. "+ Add…" is one menu. The object
  inspector is split into Transform / Material / Animation / Array groups, with counts and summaries
  in the headers.
- AI panel: compact engine switch (details in its tooltip), 3 idea chips, and one row for *start
  fresh · new chat · for terminal*.
- Export: Share and React code are the two primary actions; the code listing is under *Show code*.
  The header lost its duplicate Code button.
- Segmented controls, tabs and the engine switch take arrow keys (one tab stop per group).
- Every stored setting can be edited. The JSON boxes (object, layer, camera, whole scene, modeller
  shapes / dabs, settings) are validated by the same parsers as pieces and links. Keyframes have a
  structured editor. Modelled objects round-trip through the modeller. Scene mode has its own *View &
  interaction* section (zoom, offset, drag, scroll zoom were unreachable). Controls that scenes ignore
  (wave, colour mode, glyph colours, brightness source) are hidden there.
- JSON boxes are live and two-way. Valid edits apply as you type (coalesced undo); invalid text is
  never applied. Leaving the box, or an outside change, shows the stored value again.
- **Parity is enforced** (AGENTS.md → "Studio and JSON stay in sync"). `components/studio/coverage.ts`
  maps every stored key to its control: a new key fails typecheck until it has one, and
  `coverage.test.ts` checks the controls exist and that every gallery world survives a JSON round
  trip. This found 4 silent-loss bugs, all fixed:
  - terrain `freq` was capped at 20, but Zen garden uses 24;
  - polygon `sides` was capped at 24, but Eclipse uses 36;
  - `inner` was capped at 0.95, but Atom uses 0.96;
  - `random: false` on rain / star layers flipped back to random after a reload or share.

### Site / tooling
- Favicon + apple icon wired, `robots.ts`, `sitemap.ts`, `manifest.ts`, title template, studio OG.
- `ignoreBuildErrors` removed (type errors fail the build); GitHub Actions CI runs typecheck, tests
  and build.

## New features
- **Compressed share links** — `#z=` (deflate-raw + base64url), typically 4–8× shorter; `#s=` still
  decodes.
- **AI turn timeline** — every applied AI turn has a "Restore" button that returns the scene to that
  turn (one undo step).
- **asciinema export** — `ohmyascii bake <piece> --format cast` writes an asciinema v2 recording.
- **Frame diffing** in `ohmyascii play`: only changed rows are rewritten, which means far less output
  over SSH.

## Left open (needs a decision or infra)
- Hard rate limiting / bot protection for `/api/generate` on the deployed site: Vercel Firewall rule
  + BotID + an AI Gateway budget (dashboard settings, not code).
- Short share IDs (`/s/[id]`) with per-piece OG images — needs storage (Blob / Redis).
- World image objects keep `blob:` URLs on export; embedding as data URLs would bloat exports.
- Per-frame allocation work in the world renderer and the always-on animation loop (perf, no bug).
- Tap-to-interact canvas on phones (the canvas captures touch drags while it's interactive).
- The repo has no LICENSE file, while `packages/terminal` declares MIT; publishing is up to you.
